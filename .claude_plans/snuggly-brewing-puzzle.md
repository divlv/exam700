# Отметка «вернуться позже» и экран обзора, как в настоящем экзамене

## Context

Сейчас тест идёт строго по порядку: вопрос → ответ → оценка → следующий; после оценки последнего вопроса сессия сразу завершается. Вернуться нельзя ни к пропущенному, ни к уже оценённому вопросу.

Нужно, как в настоящем экзамене: отметить вопрос «вернусь позже» (оценка при этом не ставится и не засчитывается), идти дальше, а перед окончанием теста вернуться к отмеченным.

Принятые решения (ваши ответы):
- **Незакрытые вопросы при завершении не засчитываются** — остаются без оценки, как сейчас при прерывании сессии (`Зачтено 7 из 10`); перед завершением предупреждение.
- **Из обзора можно открыть любой вопрос**, в том числе уже оценённый, и поставить другую оценку (она заменяет прежнюю).
- **Экран обзора появляется, только если остались отмеченные вопросы.** Если все оценены и отметок нет — тест завершается сразу, как сейчас. Кнопка «Обзор» есть на экране вопроса всегда.

## Как это работает для пользователя

1. На экране вопроса (до и после показа ответа) — кнопка **«🚩 Отметить на потом»** (клавиша `M`). Оценка не ставится, вопрос получает отметку, показывается следующий.
2. Вопросы идут по порядку, отмеченные пропускаются. Когда неотмеченные закончились: есть отмеченные → **экран обзора**; нет → тест завершается.
3. **Экран обзора** — список всех вопросов сессии: номер в сессии, номер вопроса, статус (🚩 отмечен / оценка: правильно, частично, неправильно / без оценки). Строка — ссылка на вопрос. Кнопки: «К отмеченным», «Продолжить» (если есть вопросы без отметки и без оценки), «Завершить тест».
4. Открытый из обзора вопрос работает как обычно: ответ, оценка. Оценка отмеченного вопроса **снимает отметку**; оценка уже оценённого — заменяет прежнюю. У отмеченного вопроса вместо «Отметить» — «Снять отметку» (вопрос становится обычным, ждёт своей очереди).
5. «Завершить тест» с отмеченными или неоценёнными вопросами просит подтверждение: «N вопросов без оценки не будут засчитаны».

## Данные

Схема `examsession` **v4**: в `session_questions` (план сессии) колонка `marked INTEGER NOT NULL DEFAULT 0`. Отметка принадлежит строке плана, поэтому переживает перезагрузку страницы и рестарт пода, а при удалении позиции (`remove_plan_position`) уезжает вместе со строкой. Существующие сессии получают `0`. Миграция сама при старте пода; откат безопасен (старый образ колонку не читает).

Оценки по-прежнему в `session_answers` (`UNIQUE(session_id, question_id)`, upsert) — повторная оценка заменяет `grade` и `credit`, так что баллы, статистика и журнал для выбора вопросов работают без изменений. Незакрытые вопросы в `session_answers` не попадают → не зачтены и в журнале считаются «ни разу не отвеченными» (то есть при следующих выборах будут идти в приоритете — это уместно).

## Изменения

**`api/modules/examsession/repo.py`**
- Миграция v4.
- `list_plan_entries(conn, session_id) -> list[(position, question_id, marked)]` (старый `list_plan` оставить).
- `set_marked(conn, session_id, position, marked)`.
- `replace_plan_question` сбрасывает `marked = 0` (замена некорректного вопроса — новый, неотмеченный вопрос).

**`api/modules/examsession/domain.py`**
- `PlanEntry(position, question, state, grade)`: `state` — `pending` / `marked` / `graded`; для строки обзора.

**`api/modules/examsession/services.py` — `SessionRunner`**

Сегодня раннер хранит единый курсор `_index` и считает `resume` по числу оценок (предполагает, что оценены первые N позиций подряд) — с отметками это неверно. Состояние становится множествами по `question_id` (`_graded`, `_marked`), курсора нет:
- `current()` / `position` / `finished` / `upcoming()` — теперь «первый вопрос, который не оценён и не отмечен». Без отметок это в точности прежнее поведение, поэтому существующие вызовы и тесты остаются валидными; `finished` значит «неоценённых и неотмеченных больше нет».
- Новые: `question_at(position)`, `entries() -> list[PlanEntry]` (для обзора), `marked_positions`, `has_marked`, `unresolved` (отмеченные + без оценки), `complete` (все оценены, отметок нет — условие автозавершения).
- `grade(grade, position=None)` — без позиции оценивает `current()`; с позицией — любой вопрос (оценённый тоже, по решению выше). Снимает отметку; в `session_answers` пишется позиция вопроса в плане.
- `mark(position=None)` / `unmark(position)`; пометить уже оценённый вопрос нельзя (`ValueError`) — отметка означает «ответ ещё не дан».
- `flag_broken(position=None)` — тоже по позиции (из обзора можно открыть любой вопрос); логика замены/удаления из плана прежняя.
- `_resume` строится из строк плана (с отметками) и множества `question_id` оценённых — а не из числа ответов. `resume_session` соответственно.

**`web/routes/exam.py`**
- `GET /exam`, `GET /exam/answer` — как раньше для `current()`. Нет неоценённых/неотмеченных: есть отметки → редирект на `/exam/review`; нет → завершение и результаты.
- Новые `GET /exam/q/{position}` и `/exam/q/{position}/answer` — тот же шаблон для конкретной позиции (вне диапазона → обзор). Формы передают скрытое поле `position`.
- `POST /exam/grade`, `/exam/flag` принимают необязательный `position`; после действия редирект на `/exam` (он сам выберет следующий вопрос, обзор или результаты).
- Новые `POST /exam/mark`, `/exam/unmark` (`unmark` возвращает на тот же вопрос), `GET /exam/review`, `POST /exam/finish`.
- Предзагрузка картинок берёт «следующий в очереди» вопрос.

**Шаблоны и JS**
- `exam_question.html` — кнопка «🚩 Отметить на потом» / «Снять отметку» (во вторичной строке рядом с «Прервать», чтобы не занимать место на телефоне), метка «🚩 отмечен» в заголовке, ссылка «Обзор». Заголовок «Вопрос N из M» берёт позицию открытого вопроса.
- Новый `exam_review.html` — список (на узком экране карточки через уже существующую технику `table.responsive` + `data-label`), кнопки внизу, `data-confirm` на «Завершить».
- `app.js` — горячая клавиша `M`; `app.css` — стили бейджа отметки и строки обзора.

**Документация:** `CONTEXT.md` — термины **Mark** (отметка «вернуться позже») и **Review screen**; уточнить, что незакрытые вопросы не засчитываются. `CONTINUITY.md` — решения и версия схемы.

## Тесты

`tests/modules/examsession/test_session.py` / новый `test_marks.py`:
- отметка пропускает вопрос: `current()` переходит к следующему, оценка не записывается, в итог не попадает;
- `finished`, когда все вопросы оценены или отмечены; `complete` — только когда отметок нет;
- оценка отмеченного по позиции снимает отметку и засчитывается; оценка оценённого заменяет `grade` и `credit`;
- пометить оценённый вопрос нельзя;
- отметки и оценки переживают `resume_session` (в том числе непоследовательные: оценены 1-й и 3-й, 2-й отмечен);
- замена некорректного вопроса сбрасывает отметку; удаление позиции при исчерпании пула сдвигает отметки вместе со строками;
- завершение с незакрытыми вопросами: они не в `session_answers`, `Зачтено N из M`;
- миграция v3→v4: у существующих строк плана `marked = 0`.

`tests/web/test_exam_flow.py`: отметка → следующий вопрос; после неотмеченных открывается обзор со статусами; открыть отмеченный по `/exam/q/{n}` и оценить → отметка снята; открыть оценённый и переоценить; «Завершить» с неоценёнными → результаты с `Зачтено N из M`; без отметок тест по-прежнему завершается сразу после последней оценки (существующие тесты не меняются).
